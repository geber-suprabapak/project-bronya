# Project Bronya Overview

Project Bronya is a student presence (attendance) management system built with modern web technologies.

## Purpose
The project aims to provide a platform for tracking student attendance, managing permissions (perizinan), and maintaining student profiles.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4, Radix UI
- **Database**: PostgreSQL (Supabase)
- **ORM**: Drizzle ORM
- **Linting & Formatting**: Biome
- **Icons**: Lucide React
- **Validation**: Zod

## Codebase Structure
- `src/app`: Application routes and pages.
- `src/components`: Reusable UI components (including Shadcn UI).
- `src/lib`: Utility functions and third-party client initializations (Supabase).
- `src/server`: Server-side logic, database configuration, and schema definitions.
- `supabase`: Supabase-related configurations (likely migrations or functions).
